IMPORTANT MVP SCOPE:

Keep the first version simple.

DO NOT implement yet:
- Voice notes
- Audio recording
- File attachments
- PDF attachments
- Images inside notes
- AI features
- Complex collaboration
- Unnecessary cloud infrastructure

Focus on:
Notes + Todo + Focus + Search + Colors + Security +
Google Sign-In + encrypted Google Drive backup/restore.

Build and test at last.
Do not move to the next phase until the current phase works correctly.

Keep the architecture extensible so attachments, voice notes,
and AI can be added in future without rewriting the core database
or encryption architecture.

📝 Notes | ✅ Tasks | 🎯 Focus | ⚙️ More
